# Dataset Information

## Dataset Name
Iris Dataset

## Source
Scikit-learn built-in dataset

## Description
The Iris dataset is a classification dataset containing measurements
of iris flowers belonging to three different species.

## Number of Samples
150

## Number of Features
4

## Features
1. Sepal Length
2. Sepal Width
3. Petal Length
4. Petal Width

## Number of Classes
3

## Classes
1. Setosa
2. Versicolor
3. Virginica

## Data Type
Numerical

## Train-Test Split
80% training data and 20% testing data.

- Training samples: 120
- Testing samples: 30

## Preprocessing
The features were standardized using StandardScaler.

Standardization transforms the features so that they have
approximately a mean of 0 and a standard deviation of 1.

## Purpose in This Practical
The Iris dataset was used to train and evaluate a
Multilayer Perceptron (MLP) classification model.

## Evaluation
The trained MLP was evaluated using:

- Accuracy
- Confusion Matrix
