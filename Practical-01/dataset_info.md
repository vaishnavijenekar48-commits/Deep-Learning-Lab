# Dataset Information

## Dataset Name
MNIST

## Source
TensorFlow/Keras built-in dataset

## Description
MNIST is a dataset of handwritten digit images from 0 to 9.

## Training Samples
60,000

## Testing Samples
10,000

## Image Size
28 × 28 pixels

## Image Type
Grayscale

## Number of Classes
10

## Pixel Value Range
0–255 before normalization

## Normalized Range
0–1 after normalization

## Preprocessing
The pixel values were converted to float32 and normalized
by dividing by 255.

## Train-Test Split
The MNIST dataset provided by Keras already contains
separate training and testing datasets.
