# Practical 1 — TensorFlow/Keras and Data Preprocessing

## Aim

To install and configure TensorFlow/Keras in Google Colab and perform data preprocessing, normalization, train-test splitting, and data visualization on a sample dataset.

## Dataset

MNIST handwritten digit dataset.

## Tools Used

- Python
- Google Colab
- TensorFlow
- Keras
- NumPy
- Matplotlib

## Tasks Performed

1. Configured TensorFlow/Keras in Google Colab.
2. Loaded the MNIST dataset.
3. Inspected the dataset dimensions and pixel values.
4. Performed normalization of pixel values.
5. Used the provided training and testing split.
6. Visualized handwritten digit images.

## Result

The MNIST dataset was successfully loaded, preprocessed, normalized, and visualized in Google Colab.
